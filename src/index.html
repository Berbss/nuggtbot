                Accounts

                Platform credentials: Twitch, Kick, YouTube.

                ▸Twitch — credenciais
                Paste the app's Client ID. If the app is a Confidential client type (Twitch default), also paste the Client Secret — it's required to refresh the token (keeps the bot from disconnecting after a few hours). A Public client type works without a secret.
                ▸Kick — credenciais
                Kick is a confidential client — paste Client ID and Client Secret. Register redirect URI . Chat WS token = NEXT_PUBLIC_WEBSOCKET_CLIENT_TOKEN do kick.com (pra ler o chat; a Kick usa Centrifugo agora). É público.
                ▸YouTube — credenciais
                Crie um projeto no Google Cloud Console, ative a YouTube Data API v3, crie um OAuth client tipo Web application e cole Client ID + Secret. Registre a redirect URI exata no console. Faça o login pelo painel em HTTPS (o Google rejeita redirect http fora de localhost). Lê o chat da live e dispara actions/comandos como Twitch/Kick; a conta bot (opcional) envia mensagens.

                APIs

                Credenciais de APIs de terceiros (doações/eventos). Guardadas em secrets.json.

                ▸LivePix — credenciais
                OAuth2 (client credentials). Crie um app em livepix.gg e cole Client ID + Secret. Docs: docs.livepix.gg/api.
                ▸Streamlabs — credenciais
                OAuth2 (client id/secret) pra API; o Socket API token (Streamlabs → Settings → API Settings) é o que escuta doações/alertas em tempo real. Docs: dev.streamlabs.com.
                ▸StreamElements — credenciais
                Pegue o JWT token e o Account ID em streamelements.com → Account → Channels/Show secrets. Eventos de tip em tempo real via astro websocket. Docs: dev.streamelements.com.

                Backup & Restore

                Snapshots of all config (actions, commands, settings, variables, quotes, groups). Auto every hour (keeps 50). Restoring replaces everything.
